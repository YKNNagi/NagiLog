# NagiLog

## 概要

技術学習の備忘録、チートシート、デバッグ・問題解決の思考、
開発の成長過程を記録する個人技術ブログ。

ポートフォリオとして一般公開し、
「何を学んだか」だけでなく「どのように考えたか」を伝えることを目的とする。

## 開発方針

本プロジェクトでは、AIをコード生成の代替ではなく、
設計・レビュー・学習支援として活用する。

基本的な開発サイクルは、

**要件定義 → 設計 → 小さく実装 → 動作確認 → テスト → レビュー**

とする。

### 役割分担

#### 開発者（凪）

- 要件定義・仕様決定
- 設計判断
- 実装
- テスト
- 最終的な採用・不採用の判断

#### ChatGPT

- 学習サポート
- 要件・設計・実装工程の小さな単位への分解
- Django・Python等の技術解説
- 実装時のヒント・デバッグ支援

#### Codex

- 要件の抜け・矛盾チェック
- 設計レビュー
- 影響範囲レビュー
- 実装したコードのレビュー
- テスト観点の漏れチェック

Codexには原則として実装コードを書かせず、レビュー担当として利用する。

AIから提示された案をそのまま採用するのではなく、
プロジェクトの目的・学習範囲・実装コストを考慮し、
最終的な判断は開発者自身が行う。

## 利用者

### 管理者

- 管理者は1名のみ
- 記事・タグ・目標を管理する

### 一般閲覧者

- ログイン不要
- 閲覧のみ可能

## MVP

### 記事

- 記事一覧
- 記事詳細
- 新規作成
- 編集
- 削除
- Markdown本文
- タグ付与
- 作成日時・更新日時
- 固定記事（最大1件）

### タグ

- ArticleとManyToMany
- 管理者のみ作成可能
- 重複を許可しない
- 記事作成・編集時に既存タグを選択可能
- タグによる記事絞り込み

### 目標

- 未完了目標は最大3件
- 未完了目標は編集・削除可能
- 完了時に完了日時を記録
- 完了済み目標は履歴として保持
- 完了済み目標はMVPでは編集・削除不可
- 完了履歴はページ分割して表示

## TOP画面

- 固定記事
- 現在の目標
- 完了履歴への導線
- タグ絞り込み
- 新しい順の記事一覧
- 管理者ログイン時のみ管理操作を表示

## 認証・認可

- 一般ユーザー登録なし
- 未ログインユーザーはRead Only
- 管理操作は認証必須
- サーバー側でもアクセス制御する

## 安全性

- Form validationで不正入力を保存前に拒否
- Markdownを安全にHTML表示する
- Djangoの自動エスケープを維持
- 状態変更にはPOST + CSRF対策を使用
- 重要なデータ整合性はDB・モデル側でも保証
- 保存途中で不完全なデータを残さない

## 本番環境

- PostgreSQL
- nginx
- HTTPS
- DEBUG=False
- SECRET_KEY等の秘密情報をリポジトリへ含めない
- ALLOWED_HOSTSを制限
- Djangoのデプロイチェックを実施

## MVP対象外

- 一般ユーザー登録
- コメント・いいね等のSNS機能
- 下書き
- カテゴリ
- 画像アップロード
- GitHub API連携
- 高度な目標管理
- タグの編集・削除
- WAF・高度な監査機能
- DBバックアップ機能の作り込み
